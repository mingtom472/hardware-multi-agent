## 版本计划

**当前 MVP**：Python 3.12、FastAPI、Next.js / TypeScript 中文界面，独立模型供应商接口、Mock、分类/图片分支/并行分析/验证/汇总、重试和用量统计、流式文件保存及可配置资源限制。PostgreSQL、Redis、对象存储、分片上传及嵌入式软件 Agent 保留接口。

**额外 V0.1 基础扩展**：Windows 启动脚本、可选 Streamlit、真实文本协议、角色路由、SQLite 阶段记录及预算台账。外部凭据和 Windows 实机验收保持明确未验证状态。

**V0.2 协作完善**：扩展动态依赖图、独立审核、人工确认和失败恢复，完善阶段可视化；实现分片上传、断点续传与上传清理。已有并行与规则路由只覆盖其中部分。

**V0.3 电源实用工具**：完整 Buck 参数计算、示波器 CSV 增量读取、真实波形图、负载瞬态指标与可追溯工程报告。所有公式定义符号/单位/条件/过程/假设/误差，不使用图片生成模型伪造数据。

**V0.4 硬件与资料**：Qwen 真实原理图分析、Kimi 资料理解、PDF 分块/RAG、引用页码、额定值与工作条件检查、KiCad/网表基础解析。

**V0.5 工具与多模态**：ngspice 受控执行、GPT Image 生成式配图、Claude Agent SDK、工程 Skills 与工具权限。生成示意图应区别于 CAD、精确电路图和真实测量。

**V1.0 稳定工程应用**：审核案例、人工纠错、独立工程评测、成本/效果对比、工作流优化、可靠恢复、文档与平台验收。完整嵌入式软件 Agent 可继续作为后续扩展。
